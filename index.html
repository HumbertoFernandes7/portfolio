01Sobre

Perfil técnico.

Foco em Java e Spring Boot, com experiência em produtos financeiros, integrações e sistemas em produção.

Na EVIG, desenvolvo features e sustento o back-end de um assistente financeiro com inteligência artificial: integrações Open Finance, normalização de dados bancários, comunicação entre microsserviços e regras de negócio.

Stack principal: Java com Spring Boot, JPA/Hibernate e JUnit. Trabalho com PostgreSQL e MySQL, mensageria com RabbitMQ, Docker, AWS e versionamento de banco com Flyway. Sigo Clean Architecture, SOLID e Clean Code.

Formação: pós-graduação em Arquitetura e Desenvolvimento Java pela FIAP (2026) e graduação em Análise e Desenvolvimento de Sistemas pela UNINOVE (2024).
